# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-11-13

## Context
The project spans money, fairness, real-time and 3D/VR. Decisions must be traceable for engineers, auditors and the regulator.

## Decision
We record significant decisions as ADRs in `docs/adr/NNNN-title.md` (context, decision, consequences). Changes to the locked stack (plan §2) require a new ADR approved by the tech lead.

## Consequences
Small overhead per decision; clear history for audits and onboarding.
