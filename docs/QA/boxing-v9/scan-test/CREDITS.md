# Credits for the scan-test images

The boxer body and face in these images are derived from:

**"Body scan" by Artec 3D** (https://www.artec3d.com/3d-models/body-scan), scanned with Artec Leo.
Licence: Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/), as stated on the model
page (checked 2026-11-17). The `license.txt` inside the download names CC BY 3.0 Unported
(https://creativecommons.org/licenses/by/3.0/); both allow commercial use and redistribution with credit.

Modified: re-posed from a flex pose into an A-pose, re-meshed and decimated to about 18k triangles, re-rigged onto our
Bip01 skeleton, animated with CMU motion capture, dressed in simulated garments and placeholder gloves, textures
re-baked. The author does not endorse this project.

Motion: the CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu), take 14_01. The database was created with
funding from NSF EIA-0196217.

The scan source and the built GLBs are not in this repository.
